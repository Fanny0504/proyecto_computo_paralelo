\# Compresión de imágenes con PCA en cómputo paralelo



Proyecto de cómputo paralelo: compresión de imágenes mediante PCA, con versiones secuencial y paralela (Numba), y evaluación de calidad y desempeño.



\## Requisitos



Python 3.10 o superior. Instalar dependencias con `pip install -r requirements.txt`.



\## Estructura



\- `src/pca\_numba.py`: PCA por canal con kernels secuencial, paralelo y BLAS.

\- `data/`: dataset.

\- `results/`: salidas de los experimentos.

\- `docs/`: reporte.
